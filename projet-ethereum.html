Détection d'anomalies sur la blockchain Ethereum

Machine Learning non supervisé pour la détection de wallets frauduleux

Contexte du projet

La blockchain Ethereum, bien que transparente, est régulièrement utilisée pour des activités frauduleuses. Ce projet vise à identifier automatiquement les wallets suspects (adresses) à partir de leur historique de transactions, en utilisant des techniques de Machine Learning non supervisé.

Approche technique

À partir de plus de 7 millions de transactions, j'ai construit un jeu de données de 734 359 portefeuilles uniques avec des features comportementales :

  • Nombre de transactions
  • Montant total envoyé (ETH)
  • Montant moyen par transaction
  • Durée de vie du wallet (heures)
  • Fréquence des transactions
  • Taux d'erreur des transactions

Modèles utilisés

Deux approches de détection d'anomalies ont été implémentées et comparées :

Isolation Forest

Modèle basé sur des arbres de décision aléatoires, efficace pour isoler les anomalies dans des données de haute dimension.

Autoencoder (Deep Learning)

Réseau de neurones qui apprend à reconstruire des données "normales". Les wallets mal reconstruits sont considérés comme suspects.

Résultats clés

  • Isolation Forest : 7 341 anomalies détectées (1.00%)
  • Autoencoder : 36 718 anomalies détectées (5.00%)
  • Anomalies communes : 7 218 wallets (0.98%)
  • Niveaux de risque : Catégorisation en 3 niveaux (Normal, Modéré, Élevé)

Technologies utilisées

Python Pandas Scikit-learn TensorFlow/Keras Streamlit Matplotlib Seaborn

Infrastructure : Jupyter Notebook, Google Colab, GitHub, Streamlit Cloud

Application interactive

Une application Streamlit permet de visualiser les résultats et d'explorer les wallets suspects de manière intuitive.

Perspectives d'amélioration

  • Ajout de features basées sur le réseau de transactions (centralité, degré, etc.)
  • Utilisation de modèles plus avancés (Graph Neural Networks)
  • Intégration de données de labels d'escroqueries connues
  • Mise en place d'une API pour l'analyse en temps réel
